# Expense Tracker
## Description
A simple command-line based Expense Tracker developed using python.

The project allows users to manage their expenses through a menu-driven interface in the terminal.

## Features
- Add a new expense
- View recorded expenses
- Delete an expense
- Calculate the total expenses
- Exit the program

- ## Requirements
- Python 3.x
- No external libraries are required

- ## How to run
1. Install Python 3.x on your system.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   bash
   python expense_tracker.py
